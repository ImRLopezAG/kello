Create the generated connection through a Kello provider. It supplies native `rpc` options and identity-bound lifetime management; TanStack owns observers, query status, and cache updates.

```tsx
const { rpc, api } = useKello();
const tasks = api.tasks.list.useLiveQuery();
const createTask = useMutation(rpc.tasks.create.mutationOptions());
```

`tasks.list` must declare a `.live()` row-array contract. A finite contract uses `queryOptions`. Mutate from an event handler, not during render. Keep `input`, `enabled`, `select`, and callbacks inside native option arguments; no Kello wrapper is necessary.

<Callout title="One subscription supplies the first and later snapshots">
  A browser-only view does not need an extra finite query before its live query. SSR can prefetch a finite contract when
  you need server-rendered data.
</Callout>

For provider-specific sessions, follow [WorkOS](/integrations/workos), [Clerk](/integrations/clerk), or [Better Auth](/integrations/better-auth). Native option behavior is documented by [oRPC's TanStack integration](https://orpc.dev/docs/integrations/tanstack-query).
